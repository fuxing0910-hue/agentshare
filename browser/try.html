01 / Open a local transcript

Where is my JSONL? / 在哪里找文件？

Default CLI locations: Claude Code: ~/.claude/projects/<project>/<session-id>.jsonl; Codex: rollout-*.jsonl under ~/.codex/sessions/. ~ is your home folder.

Custom configuration or other clients may use a different location. Choose the session file yourself; this page does not search your folders.

以上为 CLI 默认路径，~ 表示用户目录。自定义配置或其他客户端可能不同；请自行选择要审阅的会话文件，本页不会自动查找目录。

02 / Review before sharing

You decide what leaves.

  1. Tool bodies and session metadata are omitted. Common secret patterns and your literal terms are replaced.
  2. Nothing is selected by default. Check replacements, edit remaining sensitive details, and select useful messages.
  3. Download a selected HTML or Markdown file. The review workspace itself contains all candidates; keep it local.

No upload, account, API key, analytics, or browser storage. After the page loads, processing and exports need no connection.
